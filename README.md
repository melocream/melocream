## 🚀 Marblo — 플래그십

여러 AI 코딩 에이전트(Claude · Codex · 그 외)를 **한 명의 오케스트레이터**가 지휘하는 데스크탑 앱입니다.

칸반에서 티켓을 끊으면 격리 워크트리에 에이전트가 붙고, 진행·비용·의사결정이 전부 원장에 남습니다.
