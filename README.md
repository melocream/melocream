### 🚀 Marblo — 지금 만들고 있는 것

여러 AI 코딩 에이전트(Claude·Codex·그 외)를 **한 명의 오케스트레이터**가 지휘하는 데스크탑 앱입니다.
칸반 보드에서 티켓을 끊으면 격리된 워크트리에 에이전트가 스폰되고, 진행·비용·의사결정이 전부 원장에 남습니다.

- 🌐 **웹** → [marblo.app](https://marblo.app)
- 🖥 **데스크탑 앱 다운로드** → [marblo-releases](https://github.com/melocream/marblo-releases)
- 🏢 **공식 조직** → [@marblo-app](https://github.com/marblo-app)
